How it works

  1. Pick a time.
    Tap a preset or set any length you like.
  2. Add a label.
    Pick a word and a picture: "Tidy up", "Screen time", "Carpet time".
  3. Watch it shrink.
    The colour gets smaller as time passes. When it's gone, a soft chime plays and time's up.
